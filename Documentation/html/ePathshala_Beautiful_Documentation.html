Troubleshooting

  • 401 Unauthorized: Check JWT in Authorization header; verify clock skew.
  • DB connection error: Verify MySQL port/creds; run migrations; check firewall.
  • CORS blocked: Add frontend origin to Spring CORS config.
  • Mermaid errors: Use v10.9.1; avoid injecting HTML into .mermaid nodes.
  • WS not connecting: Confirm ws endpoint, STOMP destination, and same-origin policy.

Glossary

  • RBAC: Role-Based Access Control
  • STOMP: Simple Text Oriented Messaging Protocol over WebSocket
