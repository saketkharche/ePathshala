\hypertarget{README.md_autotoc_md12326}{}\doxysubsubsection{\texorpdfstring{CSP}{CSP}}\label{README.md_autotoc_md12326}
This pacakge used to rely on {\ttfamily new Function} to compile setters and getters into fast reusable functions. Since {\ttfamily new Function} is forbidden by folks using Content Security Policy {\ttfamily unsafe-\/eval} we\textquotesingle{}ve moved away from that approach. I believe that for most cases the perf hit is not noticable but if it is in your case please reach out.

If you really want to use the old version require {\ttfamily property-\/expr/compiler} instead
