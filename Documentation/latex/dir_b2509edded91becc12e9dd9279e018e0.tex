Deep checks in React\textquotesingle{}s {\ttfamily should\+Component\+Update} should not be used blindly. First, see if a \href{https://reactjs.org/docs/react-api.html\#reactpurecomponent}{\texttt{Pure\+Component}} would work for you. If it won\textquotesingle{}t (if you need deep checks), it\textquotesingle{}s wise to make sure you\textquotesingle{}ve correctly indentified the bottleneck in your application by \href{https://reactjs.org/docs/optimizing-performance.html\#profiling-components-with-the-chrome-performance-tab}{\texttt{profiling the performance}}. After you\textquotesingle{}ve determined that you {\itshape do} need deep equality checks and you\textquotesingle{}ve identified the minimum number of places to apply them, then this library may be for you!
