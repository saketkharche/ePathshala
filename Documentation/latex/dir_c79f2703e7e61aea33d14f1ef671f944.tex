\begin{DoxyItemize}

\item Better performance than other implementations by not needing to store the whole matrix (\href{http://www.codeproject.com/Articles/13525/Fast-memory-efficient-Levenshtein-algorithm}{\texttt{more info}}).
\item Locale-\/sensitive string comparisions if needed.
\item Comprehensive test suite and performance benchmark.
\item Small\+: \texorpdfstring{$<$}{<}1 KB minified and gzipped
