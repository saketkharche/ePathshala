This monorepo uses {\ttfamily yarn}, so to start you\textquotesingle{}ll need the package manager installed.

To run E2E tests you\textquotesingle{}ll also need Playwright set up, which can be done locally via {\ttfamily npx playwright install}. Afterward, run {\ttfamily yarn start\+:app} and in a separate tab run {\ttfamily yarn e2e\+:ui} to boot up the test runner.

When you\textquotesingle{}re done with your changes, we use \href{https://github.com/changesets/changesets}{\texttt{changesets}} to manage release notes. Run {\ttfamily yarn changeset} to autogenerate notes to be appended to your pull request.
