Starting in {\ttfamily 4.\+x.\+x}, {\ttfamily Reg\+Exp.\+prototype.\+flags} is expected to be available in the environment. All modern browsers support this feature, however there may be situations where a legacy environmental support is required (example\+: IE11). If you need to support such an environment and polyfilling is not an option, creating a custom comparator that uses a more verbose comparison of all possible flags is a simple solution.
