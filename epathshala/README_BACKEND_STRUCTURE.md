# ePathshala Backend

This is the backend service for the ePathshala platform, built using Java and Spring Boot. It manages business logic, APIs, authentication, data persistence, and integrations required by the frontend.

## Project Structure

```
epathshala/
├── .classpath, .factorypath, .project, .gitignore, .gitattributes
├── mvnw, mvnw.cmd
├── pom.xml
├── README.md (original)
├── src/
│   ├── main/
│   │   ├── java/
│   │   │   └── com/epathshala/
│   │   │        ├── EpathshalaApplication.java      # Main Spring Boot entry point
│   │   │        ├── config/                        # Configuration classes (security, beans, etc.)
│   │   │        ├── controller/                    # REST API controllers
│   │   │        ├── dto/                           # Data Transfer Objects
│   │   │        ├── entity/                        # JPA Entities (database models)
│   │   │        ├── interceptor/                   # Request interceptors
│   │   │        ├── repository/                    # Spring Data JPA repositories
│   │   │        ├── security/                      # Security configuration & logic
│   │   │        ├── service/                       # Business logic/services
│   │   │        └── util/                          # Utility/helper classes
│   │   └── resources/
│   │        ├── application.properties             # Main configuration file
│   │        ├── add_questions.sql, data.sql        # SQL scripts for DB
│   │        └── ...
│   └── test/                                       # Unit and integration tests
├── target/                                         # Build output (generated)
├── uploads/                                        # File uploads (runtime, generated)
├── Various .md files (fix summaries, help, etc.)
```

## Key Files & Directories
- **pom.xml**: Maven build configuration, dependencies, plugins.
- **mvnw, mvnw.cmd**: Maven wrapper scripts for cross-platform builds.
- **src/main/java/com/epathshala/**: Main Java source code.
  - **controller/**: API endpoints for handling HTTP requests.
  - **service/**: Core business logic and services.
  - **repository/**: Database access via JPA repositories.
  - **entity/**: Data models mapped to database tables.
  - **dto/**: Data transfer objects for API communication.
  - **config/**: App and security configuration.
  - **security/**: Authentication, authorization logic.
  - **util/**: Helper and utility classes.
  - **interceptor/**: Custom request/response interceptors.
- **src/main/resources/**: Configuration and resource files.
  - **application.properties**: Main application config (DB, server, etc.)
  - **data.sql, add_questions.sql**: Database initialization scripts.
- **uploads/**: Directory for uploaded files (created at runtime).
- **target/**: Compiled output (generated by Maven, not tracked in VCS).
- **README.md, *_SUMMARY.md**: Documentation and fix/change summaries.

## Getting Started
1. Ensure Java and Maven are installed.
2. Configure `application.properties` as needed.
3. Build and run with:
   ```
   ./mvnw spring-boot:run
   ```
